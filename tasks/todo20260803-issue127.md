# Issue #127 — did:webvh: author whole-second versionTimes (Option B) + document created/updated contract (Option A)

## Context

PR #126 preserved did:webvh's fractional `versionTime` in serialized resolution metadata, but DID Core §7.3 **mandates** whole-second `created`/`updated`, so those two fields remain lossy projections of the same fractional instants. For logs whose versions differ only sub-second, serialized `updated` cannot identify the entry it came from (feeding it back as `?versionTime=` mis-selects or returns notFound), and one metadata object renders the same instant two ways.

Issue #127 (milestone 3.1.0) recommends **Option B + A**: make NetDid *author* whole-second `versionTime`s so `created`/`updated`/`versionTime` coincide exactly for NetDid-authored logs, and document that `created`/`updated` are informational, never selectors. Imported fractional logs keep today's read behavior (interop unchanged).

Spec verification (fetched did:webvh v1.0):
- Writer: versionTime "MUST be the time the DID will be retrieved by a witness or resolver, **or before**".
- Resolver: future skew beyond "a small, implementation-defined tolerance… SHOULD use a tolerance of no more than 5 minutes… MUST cause resolution to fail".
- Security Considerations refer to "the **one second** versionTime monotonicity requirement"; all spec examples are whole-second.
- Bonus: `WebVhTimestamp.Format` (`.FFFFFFF`) already emits whole-second values with no fraction/dot, exactly matching `CanonicalUtcDateTimeOffsetJsonConverter` output — no serializer change needed.

Severity: Medium (fidelity/interop defect, not a vulnerability — fractional truth stays authenticated in the log and exposed via `versionTime`/`versionId`).

## Root cause (citations)

- `src/NetDid.Method.WebVh/DidWebVhMethod.cs:148` — Create stamps raw `DateTimeOffset.UtcNow` (fractional).
- `src/NetDid.Method.WebVh/DidWebVhMethod.cs:733-744` — `GetNextVersionTime` advances by `AddTicks(1)` under contention, manufacturing sub-second-distinct versions.
- `src/NetDid.Core/Model/DidDocumentMetadata.cs:8-18` — `Created`/`Updated` whole-second vs `VersionTime` fractional (correct per DID Core; not changing).
